## SleepScienceViewer v0.2.0

### New Features
- Added display toggles for hypnogram, spectrogram, and annotations
- Hypnogram stages shown as colored background rectangles
- Annotation combo box synchronized with plots and list
- Spectrogram fallback to heatmap when sampling rate too low
- Signal color customization per channel

### Signal Viewer
- New signal raster view with adjustable epoch width (30s – 1h)
- Background sleep stage coloring
- Spectrogram/heatmap visualization per signal

### Early Feature Release
- Double-click navigation on hypnogram and annotation plots (experimental)

### Fixes
- Improved redraw persistence for custom colors
- Added legends to plots
