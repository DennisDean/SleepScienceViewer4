# SleepScienceViewer v0.5 Release Notes

**Release highlights**

Version 0.5 introduces major improvements to visualization, export, and usability across the SleepScienceViewer platform. This update enhances figure creation, expands export options, and improves overall interface responsiveness.

## New Features & Enhancements
- Spectrogram Configuration: Full control over spectrogram parameters and settings is now available.
- Expanded Export Options: Noise masks and sleep stage masks can now be saved directly for downstream analysis.
- Interactive Figures: Right-click menus added via a custom PySide6 Graphic View allow quick access to figure options.
- Figure Export Improvements: Figures can now be saved with adjustable label font sizes, DPI, and optional titles—ideal for presentation and publication use.
- Automatic Downsampling: Long signals are automatically downsampled when generating heatmaps to improve performance and clarity.
- Interface Refinements: Minor visual and layout tweaks improve figure quality and consistency across views.
- Multi-Window Support: The Sleep Science Viewer, Signal Viewer, and Spectral Analysis Window can now be opened simultaneously for integrated analysis.

## Summary

This release focuses on usability and publication-ready visualization. The addition of flexible figure export options and expanded analysis support streamlines the entire workflow—from data loading to generating final figures for papers and presentations.
